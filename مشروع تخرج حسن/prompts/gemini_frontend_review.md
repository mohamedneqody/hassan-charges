# برومت مراجعة وتطوير الفرونت-إند — انسخه كاملًا وارفق معه الملفات المذكورة

---

## البرومت (انسخ من هنا ↓)

أنت مهندس واجهات أول (Senior Frontend Engineer) متخصص في Streamlit وواجهات RTL العربية، ومصمم UI/UX بخبرة في أنظمة التصميم (Design Systems) للتقنيات المالية (FinTech).

**المهمة**: افحص ملفات واجهة تطبيق تحليل القوائم المالية المرفقة نقدًا هندسيًا صارمًا، ثم اقترح خطة تنظيف وتطوير تجعله UI احترافيًا بمعايير SaaS حديثة — **بضغط في كود محدد قابل للتطبيق مباشرة، بلا كلام عام**.

## سياق المشروع (اقرأه جيدًا قبل الحكم)

- التطبيق: تحليل قوائم مالية مصرية (EAS) — المستخدم يرفع PDF ممسوح/Excel → استخراج أرقام موثقة بسجل قرارات (سجل التحقق: كل رقم له حالة — حاسمة/تحتاج مراجعة/مفقود) → 60 مؤشرًا + نماذج إفلاس أكاديمية (Z′/Springate/Zmijewski/DuPont) + تقييم صحة مالية بأربعة أركان + تشوهات ±2σ → تقارير Excel/HTML.
- الهوية البصرية الحالية (v7): شل داكن محيطي (خلفية #0B1020 مع هالات ضوئية متحركة)، أسطح بيضاء فوقها، لونان أساسيان بنفسجي/سماوي، خط Cairo للعربي، **عربي RTL أولًا** مع تبديل EN-LTR.
- الإطار: Streamlit 1.65 — CSS مُحقن عبر طبقات: THEME_CSS (الأساس) → design_system.py (هوية v7) → polish layer.
- الواجهة: شاشة رفع (hero بطاقتين) → بعد التحليل: تبويبات (الملخص التنفيذي، المؤشرات، الجداول، الصحة بأركانها، الأنماذج الأكاديمية، مراجعة الخانات، الإيضاحات RAG، التقارير).

## الملفات المرفقة (افحصها بالترتيب)

1. `app.py` — شاشة الرفع + تدفق التحليل + التبويبات الكلاسيكية (~1800 سطر)
2. `src/dashboard/new_ui.py` — الواجهة الجديدة الافتراضية: 8 أقسام (~700 سطر)
3. `src/dashboard/design_system.py` — نظام التصميم v7: الثوابت + CSS المُحقن
4. `src/dashboard/view_model.py` — المحول القراءة-فقط من نتائج المحرك إلى عرض
5. `src/dashboard/charts.py` — الرسوم (plotly) والتنسيقات

## المطلوب — 4 مخرجات بالترتيب

### 1) جدول الإصلاحات (Audit Findings)
افحص وقيّم كل ملف على هذه المحاور، واكتب كل ملاحظة بصيغة: **[الخطورة: حرجة/عالية/متوسطة/منخفضة] | الملف والسطر التقريبي | المشكلة | الإصلاح المقترح بكود**:
- **الاتساق**: قيم ألوان/مسافات/حواف/ظلال مكررة أو متناقضة خارج نظام التصميم (magic values)، خطوط مكررة، CSS ميت (محددات لا تطابق أي عنصر فعلي)
- **التسلسل البصري**: هرمية خطوط/أحجام، تباين النصوص (contrast) على الخلفية الداكنة، فراغات الأقسام، محاذاة RTL (اتجاه الجداول، الأيقونات، الأسهم ▲▼)
- **التخطيط**: أعمدة غير متوازنة، بطاقات بارتفاعات غير متساوية، سلوك الشاشات الضيقة (كسر الجداول)، overflow
- **الحالات**: فارغ/تحميل/خطأ — هل لكل حالة عرض مصمم؟ (التحليل يستغرق دقائق — حالة الانتظار أهم شاشة)
- **UX التدفق**: خطوات المستخدم من الرفع حتى التقرير — خطوات زائدة؟ معلومات في غير مكانها؟ أزرار بلا سياق؟
- **الأداء**: re-render زائد، حسابات تعاد كل rerun، CSS ضخم يُحقن كل مرة

### 2) خطة التنظيف (Cleanup Plan)
قائمة مرتبة: ما يُحذف نهائيًا (CSS ميت/كود مكرر/مكونات بلا وظيفة)، ما يُوحَّد (tokens في design_system)، وما يُفصل (CSS الميتان خارج الطبقات). كل بند: الملف + ماذا يتغير + لماذا آمن (ماذا لن يتأثر).

### 3) ترقية الاحترافية (Professional Upgrade) — بأولوية تنفيذ
اقترح تحسينات ملموسة بكود CSS/Streamlit جاهز للنسخ، مركزة على:
- **Design Tokens موحدة**: لوحة ألوان كاملة (أساس/سطح/نص/نجاح/خطر/تحذير) + مقياس مسافات (4/8/12/16/24) + ظلال وحدود — كل شيء متغيرات CSS
- **البطاقات**: بطاقة موحدة (رأس + قيمة كبيرة + تفسير + حالة ملونة) تُعاد استخدامها للمؤشرات كلها
- **حالة الانتظار**: تصميم شاشة الانتظار أثناء التحليل الدقيقي (شريط تقدم مُصمم + رسائل مرحلية + مؤقت)
- **تبويب الصحة**: الأركان الأربعة كأشرطة تقدم ملونة بأوزانها
- **الجداول RTL**: محاذاة الأرقام يمين/يسار الصحيحة، رؤوس ملصقة، تجاوزات أنيقة
- **الحالات الفارغة**: empty states بتصميم (أيقونة + جملة + خطوة تالية)
- **Responsive**: نقاط الانكسار للجوال (المستخدم يفتحه من الموبايل)

### 4) ممنوع لمسه — قيود صارمة (تجاهلها = رد مرفوض)
- **لا تلمس منطق الأرقام إطلاقًا**: حالات سجل التحقق (حاسمة/تحتاج مراجعة/مفقود) وألوانها ودلالاتها هي عقد صدق النظام — تحسين العرض فقط، لا تغيير المعنى
- **لا مكتبات جديدة** — Streamlit 1.65 + الموجود فقط
- **العربي أولًا**: كل اقتراح يجب أن يعمل RTL صحيحًا
- **أخطاء معروفة لا تقترحها** (محلولة): تداخل CSS عبر @st.experimental_memo، إعادة كتابة التطبيق بـDash/React، استخدام st.dataframe بدل الجداول المخصصة للعربي
- اقتراحاتك يجب أن تعمل فوق **البنية الحالية** (تحسين تدريجي)، لا إعادة كتابة من الصفر

## شكل الرد المطلوب

2. خطة التنظيف بترتيب التنفيذ
